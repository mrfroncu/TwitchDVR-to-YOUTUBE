LiveStreamDVR

One LiveStreamDVR connection, shared by every queue that enables "Delete through the LiveStreamDVR API" in its own queue editor. LiveStreamDVR watches its VOD folders, and deleting them behind its back can crash it — with this enabled instead, the app asks LiveStreamDVR to delete the VOD so it stops watching it first.

Address
Password

LiveStreamDVR has no API keys — it uses the password of its own web panel. Leave it empty if the panel has none. The password is stored in the app's config and never sent back to the browser.
